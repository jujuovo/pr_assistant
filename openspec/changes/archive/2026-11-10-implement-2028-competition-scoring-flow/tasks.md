# Tasks

## 1. 正式规则数据与领域不变量

- [x] 1.1 从正式办法及附件 2 转录 2028 原子竞赛目录、A+/A/A- 分类、赛事族、合法选项、团队分配和专项参数，附逐条来源/核对清单；用目录数量、稳定标识唯一性和内容摘要黄金测试验证无合并项、遗漏项与目录外项。
- [x] 1.2 定义竞赛规则包 schema、状态、内容摘要和同周期唯一 current 约束，增加 `CompetitionRulePackage`（或等价聚合）与目录/材料关联迁移；用模型与迁移测试验证发布后不可变、历史快照可读且不能并行启用两个版本。
- [x] 1.3 实现规则包加载及发布前校验，覆盖矩阵完整性、字段模式、引用存在性、规则重叠和 2028 有效期 `2025-09-01..2028-08-31`；用无效包拒绝和有效包幂等装载测试验证。
- [x] 1.4 实现纯领域基础计分函数，覆盖国家/省级矩阵、禁止省级三等奖、个人/团队系数和非法团队排序；用表驱动测试逐组合核对候选分与拒绝结果。
- [x] 1.5 实现纯领域专项聚合管线，按 CSP、同年 ICPC/CCPC、同赛事、同作品、最高三项和 15 分封顶处理并生成稳定 reason code；用顺序无关、同分决胜、重复重算和排除项补位测试验证确定性。

## 2. 数据迁移与竞赛路径隔离

- [x] 2.1 扩展 `MaterialRecord`/OCR 任务/`ScoreEntry` 所需的规则包版本、确认词条、分组键、候选分和排除依据字段与索引，编写 upgrade/downgrade；在空 SQLite 库及目标生产数据库环境执行迁移并验证约束与回滚，不以 SQLite 结果替代生产结论。
- [x] 2.2 按已确认“现存仅测试数据”的前提编写显式清库与 2028 正式包初始化流程，执行前提供备份/预览和环境保护；在隔离测试库验证清理范围、幂等重跑及初始化后只有一个 current 包。
- [x] 2.3 为 `competition` 建立唯一类别路由，使新建/提交只写 `MaterialRecord + RuleVersion/包快照 + ScoreEntry`，其他类别保持旧 `Application` 流程；用回归测试验证竞赛不创建旧计分来源、非竞赛未被切断且不存在双计分。
- [x] 2.4 更新 API/运维文档记录新旧兼容边界、旧模型保留原因与退出条件；通过文档契约测试或接口清单审查确认竞赛端点不再声明旧权威字段。

## 3. 学生材料与 OCR 用例

- [x] 3.1 提供当前规则包摘要、可搜索原子目录和选中项目 field schema/合法选项 API，并实施学生与组织范围权限；用目录外标识、邀请赛、省级三等奖、越权请求测试验证服务端约束。
- [x] 3.2 扩展竞赛材料创建/编辑/提交用例，规范化项目名与确认字段，按 schema 校验团队总人数和排序，并固定周期及规则包；用缺字段、边界日期、区间外日期、版本冲突和规则包变化测试验证。
- [x] 3.3 实现精确重复摘要和同学生同周期阻止逻辑，同时允许同项目名称的不同级别材料进入审核；用完全重复拒绝、跨学生允许、不同级别保留和并发提交测试验证。
- [x] 3.4 实现 OCR 任务逻辑取消/废弃和材料版本 CAS，分别保存 OCR 原文与学生确认快照；用停止后手填、OCR 失败手填及迟到结果不得覆盖的工作线程测试验证。
- [x] 3.5 实现退回材料的新版本编辑、重新提交和放弃动作，保留原意见与全部历史且不解析意见文字；用状态机、越权、版本冲突和审计事件测试验证。

## 4. 教师审核与原子计分

- [x] 4.1 收紧竞赛审核命令 schema 为 `approve`/`return`、意见、材料版本和幂等键，明确拒绝规则/事实/分数改写字段；用教师授权范围、非法动作和伪造 `override_score` 等契约测试验证。
- [x] 4.2 实现只读审核上下文，返回原件入口、OCR 原文、学生确认值、固定规则依据和后端候选分；用附件访问控制与字段不可写测试验证教师只能核验和填写意见。
- [x] 4.3 建立竞赛审核计分用例事务：锁定材料与学生、写审核结论、计算并写明细、专项重分配、重建周期快照、使 draft 排名失效并审计；注入各阶段失败验证完整回滚。
- [x] 4.4 实现审核命令幂等语义和并发版本检查；用相同键相同载荷重放、相同键不同载荷冲突、双教师并发和超时重试测试验证不重复计分。
- [x] 4.5 实现教师按授权学生查看竞赛汇总的只读 API，展示项目名、关键字段、状态、候选/计入分和材料入口；用组织越权与“可退回但不可编辑/合并/改分”测试验证。

## 5. 规则更正与派生结果失效

- [x] 5.1 实现规则包更正影响预览，对比旧/新匹配、候选分和受影响材料且不写数据；用无影响、映射变化、分值变化及历史快照测试验证报告完整。
- [x] 5.2 实现新包切换事务，保留旧包、将受影响材料置为显式待重新确认、审计失效旧分、重建学生快照并使 draft 排名失效；用故障注入验证不能出现“新包已启用但旧分仍有效”等部分成功。
- [x] 5.3 实现可重试通知意图和发送器，使通知失败不回滚规则切换；用发送失败、幂等重试及学生未确认前不自动重提/改分测试验证。
- [x] 5.4 实现学生重新确认产生新版本、教师重新审核后才生效的新链路；用旧历史保留、未确认显示、再次通过后的分数替换和重复累计防护测试验证。
