# 3.3 OCR 辅助分支与人工 fallback

记录日期：2026-11-11（Asia/Shanghai）

## 实现

- 页面明确说明 OCR 只用于辅助预览，不认定真实性、审核结论或最终加分。
- OCR pending 时继续展示学生确认事实。
- OCR failed 时显示人工处理建议，保留学生确认事实与表单。
- OCR completed 但置信度低于 0.8 时显示人工核对提示，不把机器猜测写入确认值。
- OCR 服务不可用时显示中性服务错误，人工表单与已确认事实仍保持可用。
- 迟到结果继续通过既有 `late_result_ignored` 状态隔离。

## 真实挂载验证

```powershell
npm.cmd --prefix frontend run test:mounted
```

结果：`1 test file passed, 11 tests passed`。

OCR 挂载场景断言：

- queued/pending：显示状态与人工项目名称，未调用 `createRecord`；
- failed：显示“继续使用人工填写”，人工事实不变；
- low confidence：显示“置信度较低”，DOM 不出现机器猜测值；
- HTTP 503：表单仍存在，人工事实仍存在，并显示 backend-unavailable 中性说明。
