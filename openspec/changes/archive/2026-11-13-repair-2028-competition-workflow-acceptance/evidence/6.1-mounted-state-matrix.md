# 6.1 学生与教师竞赛页面挂载状态矩阵

记录日期：2026-11-11（Asia/Shanghai）

## 命令

```powershell
npm.cmd --prefix frontend run test:mounted -- --reporter=verbose
```

初次结果：`2 passed` test files，`22 passed` tests。

补齐退回后修正稿编辑链路后再次运行同一命令：`2 passed` test files，`25 passed` tests。新增真实挂载覆盖：创建补正稿后自动载入、PATCH 使用当前版本、保存后按刷新版本提交、不重复 POST 创建，以及 stale PATCH 冲突时保留输入。

## 覆盖矩阵

- 学生首页：竞赛权威计数 success、loading、actionable error；与非竞赛兼容申请分区。
- 学生竞赛页：loading、empty、success、validation、permission、configuration、conflict、backend unavailable、search empty、附件缺失、重复材料、人工 OCR pending/failed/low-confidence/unavailable。
- 教师首页：竞赛待审数来自 workbench summary；非竞赛兼容数显式排除旧竞赛 Application。
- 教师竞赛审核页：loading、empty、success、permission error、待审只读详情、通过、退回、已处理只读状态。
- 请求责任：首次加载、刷新、目录选择、搜索合并、删除草稿、撤回和审核动作均由 request spy 验证预期调用次数/参数。

测试使用 Vue Test Utils 挂载真实 `.vue` 组件及 happy-dom 焦点行为，不是 helper 测试或源码字符串搜索。真实浏览器与辅助技术验收仍按后续门槛单独执行。
