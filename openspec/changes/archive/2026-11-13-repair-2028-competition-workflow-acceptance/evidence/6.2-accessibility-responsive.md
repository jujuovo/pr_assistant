# 6.2 键盘、可访问关联与响应式验证

记录日期：2026-11-12（Asia/Shanghai）

## 自动验证

```powershell
npm.cmd --prefix frontend run test:mounted -- --reporter=verbose
```

最近一次全量真实挂载结果为 `3 passed` test files、`31 passed` tests。相关断言覆盖：

- 表单 `label` 与稳定控件 ID 关联；
- 字段错误使用 `aria-invalid`/`aria-describedby`；
- 错误摘要为 `role=alert`，提交失败后获得焦点；
- 摘要错误项可把焦点移到附件或对应字段；
- 教师审核意见为空时聚焦 textarea，且不发出审核请求；
- loading 使用 `role=status`，可操作错误使用 `role=alert`。

## Microsoft Edge 人工键盘验收

浏览器操作全部由用户在宿主 `http://localhost:5173/` 人工执行，Codex 未控制浏览器。用户确认完成以下检查且未报告问题：

1. 仅使用 `Tab` 依次经过目录搜索、材料字段、附件与保存/提交操作；焦点可见且顺序合理。
2. 必填内容为空时触发保存；焦点移动到错误摘要。
3. 从错误摘要激活错误项后可定位到对应字段。
4. 使用 `Shift+Tab` 反向移动；没有键盘陷阱或不可操作控件。
