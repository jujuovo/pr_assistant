# 1.2 单一后端权威竞赛上下文

记录日期：2026-11-11（Asia/Shanghai）

## 实现结果

- 新增 `GET /api/materials/competition/context`，从唯一 active `RecommendationCyclePolicy` 选择同周期 `global/current` `CompetitionRulePackage`。
- 响应包含周期、规则包 ID/版本/摘要、证据区间、完整目录摘要、字段 schema、可用状态和按角色返回的 `allowed_actions`。
- 响应使用规则包摘要作为 `ETag`；客户端提供过期 `If-Match` 时返回 HTTP 409 与稳定 code `competition_context_version_conflict`。
- 缺少活动周期、缺少 current 包、包无效、周期不一致和无权限均保留独立稳定 code，不再由读取端硬编码自然年选择规则包。
- 原 current/package/catalog 读取复用同一上下文选择逻辑。
- 学生和教师页面以及 `materialApi` 不再包含竞赛周期 `2028` 常量；records、feedback、summary 和草稿创建均使用上下文返回的 `cycle.cycle_code`。
