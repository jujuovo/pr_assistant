# 2.2 本地正式包准备失败语义

记录日期：2026-11-11（Asia/Shanghai）

## 实现

- 共享账号/测试规则 seed 与 2028 周期及正式包装载在同一数据库事务中完成。
- 缺少规则源返回 `competition_package_source_missing`，消息包含缺失路径和恢复后重试建议。
- 无效 JSON 返回 `competition_package_source_invalid`。
- 语义无效规则先经过正式领域校验，返回 `invalid_competition_package` 等领域 code，不泄漏裸 `KeyError`。
- 已存在不同 current 包时返回 `competition_package_already_current`，要求显式处理冲突，不覆盖或退役原包。
- fresh database 准备失败时回滚并删除新建 SQLite 文件；已有数据库失败时回滚并保留原数据库。
- 正式启动仍默认使用仓库内 `backend/rules/competition_2028.json`；显式 `--competition-package-file` 仅用于可重复的替代来源/故障测试。

- 冲突后仍只有原 `2028/global/current` 包，digest 未变化，三个共享账号仍存在。
