# 4.1 学生竞赛申报产品级布局

记录日期：2026-11-11（Asia/Shanghai）

## 实现与 DOM 验证

- 沿用现有 `card`、`form-control`、`btn`、状态徽标及统一蓝色视觉语言。
- 页面层级包含：标题/说明、权威周期与规则包摘要、正式目录搜索、材料事实分组、附件/OCR/提交区、权威计分反馈和申报顺序。
- 表单采用明确标签与控件关联，条件字段随参赛方式/赛事族显示。
- 桌面使用主内容加反馈侧栏；980px 以下改为单列主内容；640px 以下表单、摘要、事实对照和操作按钮按阅读顺序单列。
- 真实 Vue 挂载测试编译并挂载页面，验证产品区块、标签关联、附件输入和操作区。

```powershell
npm.cmd --prefix frontend run test:mounted
npm.cmd --prefix frontend run build
```

结果：挂载测试 `12 passed`；生产构建成功（147 modules，仅既有 chunk 大小警告）。
