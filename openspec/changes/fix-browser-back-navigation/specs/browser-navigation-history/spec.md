# Spec Delta

## Purpose

定义三角色站内页面导航如何写入浏览器历史，使用户按浏览器后退键时返回上一个业务页面，而不是直接回到登录页。

## ADDED Requirements

### Requirement: 站内前进导航保留浏览器历史
系统 SHALL 在用户主动切换站内页面时新增浏览器历史记录，不得用替换当前记录的方式跳转；目标页面与当前页面相同时不得新增重复记录。

#### Scenario: 侧边栏切换后后退
- **GIVEN** 学生、教师或管理员从角色首页点击侧边栏进入另一个业务页
- **WHEN** 用户按浏览器后退键
- **THEN** 浏览器回到上一个业务页，而不是登录页

#### Scenario: 分类进入材料页后后退
- **GIVEN** 学生从「提交材料」评测项目卡片进入材料工作台
- **WHEN** 用户按浏览器后退键
- **THEN** 浏览器回到评测项目页

#### Scenario: 材料页进入我的材料后后退
- **GIVEN** 学生从材料填写或竞赛页点击「我的材料」
- **WHEN** 用户按浏览器后退键
- **THEN** 浏览器回到刚才的材料页

#### Scenario: 重复点击当前页面
- **GIVEN** 用户已经位于某个业务页
- **WHEN** 用户再次点击同一个侧边栏入口
- **THEN** 系统不新增重复历史记录

### Requirement: 登录成功不把登录页留在历史
系统 SHALL 在登录成功后替换登录页对应的历史记录，使用户从角色首页后退时不会回到登录页。

#### Scenario: 登录后立即后退
- **GIVEN** 用户刚刚从登录页成功进入角色首页
- **WHEN** 用户按浏览器后退键
- **THEN** 浏览器不会回到登录页；用户仍通过注销按钮退出登录

#### Scenario: 注销后回到登录页
- **GIVEN** 用户已登录角色端
- **WHEN** 用户点击注销
- **THEN** 系统替换当前历史进入登录页，登录页不成为角色业务页的后退目标

### Requirement: 清理与重定向使用替换
系统 SHALL 对页内参数清理、注销、未登录重定向和显式逻辑返回使用替换导航，避免产生无意义的历史记录。

#### Scenario: 取消编辑清理参数
- **GIVEN** 用户正在编辑材料并取消编辑
- **WHEN** 系统清除 `editId`
- **THEN** 使用替换导航，不新增一条历史记录

#### Scenario: 未登录访问受保护页面
- **GIVEN** 用户未登录或会话失效
- **WHEN** 用户访问角色业务页
- **THEN** 系统重定向到登录页，不使用会堆积业务历史的导航方式

#### Scenario: 显式返回上一逻辑页
- **GIVEN** 用户从评测项目进入材料表单后点击「返回评测项目」
- **WHEN** 系统执行显式逻辑返回
- **THEN** 使用替换导航回到评测项目，不把表单页留在后退目标中
