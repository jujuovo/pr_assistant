# 志愿服务OCR比对与申诉

本变更仅负责 f22b607 主干新增志愿服务累计工时入口的OCR准入、自动打回和申诉，不认领其他活动变更任务，不修改任何归档。

学生继续手填并单次上传。保存时进入持久后台队列；识别工时、明确工时类别、系统录入并审核通过日期，三项比对通过才允许正式提交教师。字段不同、缺失、识别失败或不支持格式自动打回。学生可填写理由申诉，保留原OCR与差异，转人工审核并重点标记。教师审核通过后沿用原累计工时及评分事务，OCR不证明真实性。

用户已确认三个字段都参与比对，无法识别（含PDF）同样打回并允许申诉。保留“待提交”与学生正式提交环节，不擅自提交草稿。
