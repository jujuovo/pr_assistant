# 设计

复用 OCRJob 和现有带租约的 worker，不新增外部队列。新增可空 material_record_id/material_version/attachment_id 绑定字段、索引及可回滚迁移；本地 prepare_local 同步兼容旧开发库。公开七类OCR目录不变，志愿任务仅通过材料入口创建。

新增 volunteer_material 提取器，复用 PP-OCRv5_mobile，原始工时、签到/签退、录入时间按坐标提取。按用户最新规则，匹配信用/荣誉界面后类别按普通志愿服务；信用日期取签退日、荣誉日期取录入日，记录platform_policy版本及证据，不将该解释伪装成截图原文。缺字段、候选歧义、证据质量不足均不能算一致。多附件逐张处理、按明确类别汇总原始小时，再与申报的普通/减半工时分别比较；评分环节才减半。日期须一致；重复图片不能重复累计。

analysis.volunteer_ocr 保存输入摘要、版本、任务ID、比对项与打回原因；ocr_raw_terms 保存逐份报告。任务租约及材料版本双重防护，修改后旧任务不覆盖新材料。提交及审核通过时再次核验全部原件摘要。PDF、坏图等无可运行任务时立即记录打回，保留申诉入口。

申诉仅本人、当前输入、系统打回且未申诉的材料可用；理由必填，版本控制、申诉事件和正式提交在一个事务。analysis.volunteer_appeal 保留理由、时间、申请人及原任务快照。后端提供 allowed_actions、workflow_state、priority_review；教师列表优先展示申诉，突出原差异。识别不改写手填字段，不跳过教师审核。

不修改正式竞赛、旧志愿费率、校方政策与既有分值。生产数据库锁与迁移未验证。浏览器由用户手动操作；mounted、真实模型合成样本和接口测试分别记证据，不冒充浏览器验收。
