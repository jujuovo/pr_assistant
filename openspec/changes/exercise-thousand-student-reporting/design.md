# 设计

创建可重复运行的命令行工具，明确指定本地SQLite路径，拒绝生产环境和仓库源库。固定命名空间，逐学生事务和检查点；只接续完整学生，冲突则停止。保留在线备份和账号清单。

每名学生均覆盖14种材料类型，另含多次竞赛、论文、创新训练、干部与志愿服务；按场景分配已审核、未审核、退回、驳回、零分、超限、重复制约。合成PDF明确标注测试，实际写入私有附件存储。志愿PDF通过实际OCR不支持格式退回及申诉人工路径，不伪造OCR成功。

独立Decimal期望值校验全部学生快照，核对教师和管理员的逐专业报表，比较排名与导出数据。额外验证权限、无效输入、重复请求、过期版本。规模为顺序集成测试，不宣称并发吞吐或浏览器验收。

实测修复范围：统一教师汇总的可计分材料类别；竞赛工作台先筛状态再以材料ID倒序游标分页，前端保留已加载页、去重并支持错误重试；为MaterialEvent(record_id,id)、MaterialAttachment(record_id,id)、ScoreEntry(material_record_id,status)加入读取索引。现有本地库通过prepare_local的幂等索引准备补齐，正式迁移提供独立Alembic revision，生产迁移未验收。
