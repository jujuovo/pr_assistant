# 实现边界

统一legacy_application_policy负责登录身份、学生归属、学院审核边界、状态与系统字段保护。创建身份从学生档案绑定；编辑/删除只允许本人，审核仅本学院教师/管理员且仅pending。审核身份取会话，不信任请求内姓名。已处理申请不能直接重审、修改或删除。

迁移闸门同时检查类别、sub_type、申请原绑定规则及拟绑定规则，阻止更换标签或清空rule_id绕过；其他学院规则禁止引用。已迁移类别返回409和MaterialRecord入口，历史读取保持。

删除只允许未关联证据的本人draft。识别、材料、批次、计分事实（含失效历史）和审核命令都保护；其余真实外键由IntegrityError回滚兜底。数据库提交成功后才清理规范附件路径，失败保留原件。CertificateAssessment反向关系移除ORM删除级联，由RESTRICT阻止父删除，覆盖关联已加载/未加载情况。

迁移反射实际外键名：SQLite对未命名外键补命名约定并重建表；PostgreSQL保留原约束名原地替换。重建前发现证据孤儿则停止，不擅自修数据；已为目标规则则幂等退出。PG分支尚未在真实PG执行。

演练工具以只读连接读取源库，使用SQLite backup取得一致性副本，拒绝覆盖旧文件；只在副本调用该外键迁移两次并逐表比对行数与摘要、检查外键。工具不更新alembic_version，不是生产升级命令。本轮不升级原开发库。
