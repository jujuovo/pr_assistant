# 当前材料能力与维护边界

更新基线：main @ 414dda8、低风险维护及旧兼容入口最小修复（2026-11-21）。本页说明实现状态，不代替政策原文或后台规则版本。

## 能力标识

GET /api/materials/types 的 auto_bonus_enabled 表示“类别支持教师核验后按规则计算分数”，不是免审核，也不保证每一条材料都符合计分条件。单条材料能否操作以 allowed_actions、固定规则版本和审核结果为准。OCR能力独立由 recognition_status 标示；后端已有适配不等于所有上传页面都会自动调用。

| 类别 | 教师核验后规则计分 | OCR与前端接入 |
|---|---|---|
| competition | 支持，正式目录和固定规则包 | 部分已适配赛事保存后后台识别；其他赛事人工核验 |
| volunteer | 支持，按通过材料的工时累计 | 信用/荣誉截图后台核对工时、普通志愿服务类别、服务记录日期 |
| research_paper / invention_patent | 支持，教师核定目录、署名及条件 | 尚无对应OCR，不能把自动算分标示为自动识别 |
| innovation_training | 支持，教师核定结题、级别和角色 | 尚无对应OCR |
| student_work | 支持，核定任职考核后按规则计分 | 任职证明有后端适配；页面人工申报/核验，不等于全量自动OCR |
| social_practice / research / certification / competition_evidence | 人工核验，不启用本类别正式规则计分能力标识 | 部分证明有独立后端适配，日常材料页保留人工通道 |
| arts_sports | 人工核验 | 无OCR，不自动计分 |
| academic / language / honor | 未启用本类别正式规则计分能力标识 | 结构化录入或旧兼容流程，不能当成已完成本类别政策引擎或OCR |

## 志愿服务现状

每份材料填本次工时；教师通过后累计同周期已通过材料的普通工时和减半工时，重新计算一个有效累计计分结果。旧计分条目失效是为了避免重复算累计分，不等于用新报表替换旧材料工时。存在旧累计报表模式的历史计分时返回409，须先人工对账。

平台截图按用户确认规则：信用、荣誉时数界面按普通志愿服务核对，信用记录按签到签退并取签退日期，荣誉取录入日期。识别不证明真实性；审核和申诉继续保留。详细操作见 volunteer-material-ocr.md。

## 时间与材料入口

材料详情、事件、最近审核及竞赛工作台的时间戳统一为带Z的UTC ISO字符串。前端按业务需要显示北京时间。获奖日期、服务记录日期等纯日期仍为YYYY-MM-DD，不附加时区、不做8小时换算。

发明专利与科研论文等已迁移类别必须从MaterialRecord入口提交。旧Application入口返回409及正确的新路由；该拦截不删除任何历史申请或评估证据。
