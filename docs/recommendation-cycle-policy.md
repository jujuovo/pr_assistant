# 推免周期政策与日期资格接口

系统以一个全局活动推免周期作为所有学院提交、审核、计分和后续排名的共同上下文。周期代码为四位整数，例如 `2026`；它表示计分归属，不等于奖状的自然年份。`award_date` 只用于判断证据日期是否位于该周期政策的有效区间。

周期政策采用不可变版本。政策内容变化时创建新版本并显式切换活动引用，已经固定在申请、材料或计分事实上的旧版本不随之改变。有效日期区间的起止日均包含，API 以 `boundary: "inclusive"` 明示这一语义。

## 当前活动周期

授权客户端使用 `GET /api/workflow/cycles/current` 读取全局上下文。接口要求已登录，但不按学院返回不同周期；学生、教师和管理员读取的是同一个活动版本。成功响应为：

```json
{
  "cycle_code": 2026,
  "display_name": "2026 推免周期",
  "policy_version": 1,
  "status": "active",
  "eligible_award_start_date": "2023-09-01",
  "eligible_award_end_date": "2026-08-31",
  "boundary": "inclusive",
  "activated_at": "2026-01-02T03:04:05Z"
}
```

未登录返回 `401`。系统没有完整活动政策时返回 `409` 和稳定错误码 `cycle_policy_missing`，客户端不得改用本机年份或奖状年份兜底。

## 日期资格语义

- `award_date` 在开始日或结束日当天：合格。
- `award_date` 位于区间外：材料真实性仍可通过，但计分资格应表达为不符合本周期，不能解释为材料造假或教师拒绝。
- `award_date` 缺失或无法确定：阻止完成计分并要求补正，不能默认合格或用零分掩盖。
- 正式提交时固定周期及政策版本；补正、重提、审核、撤销和重算继续使用已固定版本。
