## 志愿工时

普通累计工时 + (大型赛会及支教累计原始工时 / 2) = 有效累计工时。
200小时不赋基础分；200小时后每满2小时加0.05分，不足2小时不计，封顶1分。
普通与减半工时必须互斥，上传志愿者管理系统累计报表，教师核验服务对象认可和系统审核通过日期。
新累计报表通过时原计分明细失效，保留历史，不与旧累计值相加；日期更早的报表不能替代更新报表。
志愿表彰是第8页另一项，单独封顶1分，尚未实现，不能当成工时填入。
旧 automation 费率链路不再接受2028及以后周期的提交或审核。
