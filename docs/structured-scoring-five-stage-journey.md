# 结构化计分五段操作旅程

本清单用于学生、管理员和教师在隔离测试数据上验收“证明材料 → 规则覆盖 → 学生确认 → 教师核验 → 权威计分”。OCR 只提供可修改的提取建议，规则匹配只读取学生确认后的结构化字段。

## 一、学生保存无规则材料

1. 学生上传材料，核对并确认竞赛名称、奖项等级、竞赛级别、赛区、组别、赛道和获奖日期。
2. 若没有唯一已发布规则，保存结果必须为 `rule_unmatched`。
3. “我的项目”显示 0 分、未审核和“材料词条没有对应计分”。
4. 核对教师待审核列表中没有该材料；数据库中没有对应 `ScoreEntry`，没有因该材料新建 `StudentScoreSnapshot`。

## 二、管理员补充规则

1. 管理员在“规则管理”的未覆盖词条聚合中查看本学院影响数量；聚合结果不得包含学生身份或附件。
2. 从聚合词条起草规则，补全周期、学院、材料类别及全部匹配维度，预览候选分和冲突。
3. 冲突为零后发布不可变规则版本。发布后材料只能变为 `rule_available`。
4. 核对发布动作没有替学生提交、没有创建教师任务、没有核验或计分。

## 三、学生重新确认

1. 学生刷新“我的项目”，查看规则版本、候选分及原结构化申报信息。
2. 放弃或不勾选确认时，材料保持 `rule_available` 和未审核。
3. 学生明确确认当前材料版本和规则版本后重新提交，材料变为 `submitted`，同时固定活动周期、政策版本和规则版本。
4. 若页面提示版本冲突，必须刷新并重新确认，不能重复点击绕过。

## 四、教师只核验正式提交材料

1. 教师待审核列表只显示已固定规则版本的 `submitted/under_review` 材料。
2. 教师核对原件与学生确认字段，可选择通过、拒绝或要求补正；无规则材料不是教师责任。
3. 正常通过时不要求教师填写最终分，系统使用固定规则版本的自动分；人工改写必须有权限和理由。
4. 直接访问 `rule_unmatched/rule_available` 地址或构造审核请求应返回拒绝。

## 五、学生查看权威结果

1. 审核成功后，同一事务生成 `ScoreEntry`、重建 `StudentScoreSnapshot`、更新兼容投影并使相关 draft 排名失效。
2. 学生页面显示规则版本、自动分、人工调整、实际计入分和周期总分；刷新后结果不变。
3. 若只有未审核材料，页面必须显示“尚无权威计分快照”，不能回退旧汇总字段伪造总分。
4. 日期不合格显示 `verified_not_eligible`；需要补正显示 `needs_correction`，两者都不能伪装成计分成功。

## 验收记录

每次人工演练记录测试日期、环境、三个测试账号、材料 ID、规则版本 ID、周期政策版本 ID、`ScoreEntry` ID、快照 ID及实际结果。未运行真实 OCR 时必须注明“仅验证人工确认路径”，不得记录为真实 OCR 通过。
